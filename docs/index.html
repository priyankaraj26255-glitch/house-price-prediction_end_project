Workflow

1. Data & EDA

Cleaned missing values, explored skew, correlations and neighborhood effects.

2. Features

Engineered house age, space per bedroom and bath/bed ratio inside a leak-free pipeline.

3. Modeling

Ridge, Random Forest and Gradient Boosting compared with 5-fold CV, then tuned.

4. Deployment

Flask web app + JSON API, Docker image and pytest suite.

Usage

curl -X POST localhost:5000/predict -H "Content-Type: application/json" \
  -d '{"sqft":1800,"bedrooms":3,"bathrooms":2,"year_built":2005,"lot_size":5500,
       "garage_spaces":2,"overall_quality":7,"has_pool":0,
       "dist_to_center_km":6,"neighborhood":"Oakwood"}'
